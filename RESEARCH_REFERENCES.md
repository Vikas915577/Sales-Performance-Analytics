# Research references — Sales Performance Analytics

Official Infor documentation used to shape the Birst implementation blueprint. Exact interface labels can vary by tenant/release; use documentation that matches the Birst environment you actually access.

1. [Preparing to use Birst (Infor docs)](https://docs.infor.com/birst/2026.x/en-us/birstolh/intro_user/jdj1655271231404.html) — end-to-end workflow spanning data setup, model, measures, subject areas and reporting.
2. [Creating dashboards (Infor docs)](https://docs.infor.com/birst/latest/en-us/birstolh/dashboards_user/ifj1655271234451.html) — pages, dashboard objects/dashlets, filters and publishing.
3. [Subject areas (Infor docs)](https://docs.infor.com/birst/latest/en-us/birstolh/reports_user/bha1655271152572.html) — organize business-friendly attributes and measures for report authors.
4. [Filtering data in Visualizer (Infor docs)](https://docs.infor.com/birst/2025.x/en-us/birstolh/reports_user/xah1655271135431.html) — filtering behavior in analytic reports.
5. Project-specific rules are documented in [DDD user story and acceptance criteria](DDD_USER_STORY_AND_ACCEPTANCE_CRITERIA.md), [data dictionary](data_dictionary.md) and [Birst blueprint](dashboard_blueprint.md).

The repository’s demo records are synthetic. If you switch to a public dataset, record the source URL, license, download/version date, covered period, data transformations and currency before interpreting the findings.
