# Upload this project to GitHub (simple steps)

## Create the repository
1. Sign in to your GitHub account.
2. Choose **New repository**.
3. Use the name `sales-performance-analytics`.
4. Set visibility to **Public** only if you are comfortable sharing the code and synthetic sample data.
5. Do not add a separate README/license during creation because this project already includes them.

## Upload the files
1. Download and extract `Sales_Performance_Analytics_Project.zip` on a computer, or use a Git client on your phone that supports uploading folders.
2. Open the new repository, choose **Add file → Upload files**, and upload the extracted project contents (not the outer ZIP as the only repository file).
3. Check the repository tree contains `README.md`, `src/`, `sql/`, `docs/`, `data/sample_data/`, `outputs/demo/`, `requirements.txt`, and `LICENSE`.
4. Wait for GitHub to finish and open the README to confirm formatting.

## Before putting it on a resume
- Run it against the official UCI dataset, not only the synthetic sample.
- Replace or clearly label demo-only outputs.
- Read and understand the SQL queries and Python script.
- Add a month/year to the resume only after completing your analysis.
- Share the repository URL only after you have opened it and confirmed that it is public and working.

This guide does not publish the repository automatically; it explains the manual steps.
